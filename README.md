# Orientador Vocacional - CEET Giuseppe Altoé

Este projeto é uma plataforma de orientação vocacional desenvolvida especificamente para alunos do CEET Giuseppe Altoé. O objetivo é auxiliar os estudantes a identificarem sua área de afinidade dentro dos cursos técnicos oferecidos, utilizando um quiz interativo que mapeia competências e interesses individuais.

## 🚀 Sobre o Projeto

O Orientador Vocacional utiliza uma lógica baseada em pesos para analisar as respostas dos usuários, entregando ao final do teste um diagnóstico personalizado sobre qual perfil de carreira técnica mais se alinha ao estudante, fornecendo dados sobre média salarial, mercado de trabalho e as disciplinas chaves dentro da grade curricular do CEET.

## 🤖 Propósito: Feira de Cursos CEET

Este sistema foi desenvolvido como uma ação interativa para a **Feira de Cursos do CEET Giuseppe Altoé**, que ocorrerá no dia **28/05/2026**. 

A proposta foi idealizada pela nossa **equipe de robótica** como uma forma de acolher e engajar os futuros estudantes que visitarão nossa instituição. Queremos proporcionar uma "brincadeira" tecnológica que ajude os visitantes a entenderem melhor o vasto mundo da TI, tornando a experiência de conhecer o CEET muito mais dinâmica e memorável.

Se você está visitando a feira, venha nos encontrar no estande de robótica e teste o seu perfil!

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas voltadas para performance e usabilidade:

* **Frontend:** HTML5, CSS3 (com design responsivo e variáveis dinâmicas) e JavaScript (Vanilla).
* **Backend & Integração:** Supabase (utilizado como serviço de Backend-as-a-Service para armazenamento dos dados).
* **Estrutura:** Design focado em experiência do usuário (UX) com foco em mobile-first.

## 📱 Funcionalidades

- **Quiz Dinâmico:** Perguntas focadas no contexto escolar e técnico do CEET.
- **Resultados Personalizados:** Cada área possui uma identidade visual única, com paleta de cores própria definida via JavaScript.
- **Persistência de Dados:** Todos os resultados são enviados e salvos em tempo real em um banco de dados remoto.
- **Responsividade:** Layout adaptado para rodar perfeitamente em smartphones, tablets e desktops.

## 💻 Como Rodar o Projeto

1. Clone este repositório para sua máquina local.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Não é necessário instalar dependências adicionais, pois todos os scripts são carregados via CDN.

## ⚠️ Observações Importantes (Status do Projeto)

Informamos que este projeto está hospedado utilizando **serviços e plataformas de infraestrutura gratuita** (como o nível *Free Tier* do Supabase e plataformas de hosting estático).

Devido à natureza dessas limitações técnicas:

* **Indisponibilidade:** O serviço pode, eventualmente, sofrer períodos de inatividade ou manutenção automática pelas plataformas de hospedagem.
* **Tempo de Resposta:** É possível notar uma leve lentidão no carregamento inicial da aplicação, devido ao tempo de "acordar" (cold start) dos bancos de dados gratuitos após períodos de ociosidade.
* **Uso:** O sistema foi projetado para uso acadêmico e demonstração de portfólio.
